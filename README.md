## Building now

- **[craftie](https://github.com/Jitheswar/craftie)**: an AI coworker for Minecraft. It joins your world as a second player, takes requests in chat ("build me a house", "get 20 iron") and works out every step itself. TypeScript.
- **[JithuBrowser](https://github.com/Jitheswar/JithuBrowser)**: a privacy-focused browser built on official Chromium. Sites and extensions keep working, but pages can't fingerprint you or watch what you do. Pre-release for Linux and Windows.
- **[NexCC](https://github.com/Jitheswar/CD_Project)**: an optimizing compiler for a C subset where every stage is visible, from automata and parse tables through SSA to RISC-V code, with a bytecode VM you can step backwards. Built with a teammate.

## Machine learning

- **[sih26038](https://github.com/Jitheswar/sih26038)**: diabetic retinopathy screening for rural India (SIH 2026). It checks its own explanations against lesion evidence and sends unclear cases to a person. Validation sensitivity 0.982, specificity 0.917.
- **[RSNA](https://github.com/Jitheswar/RSNA)**: our team's solution for the RSNA 2026 knee MRI Kaggle competition. 12 findings, 4,407 studies, and only 58 with reference labels.
- **[Ayur-Ai](https://github.com/Jitheswar/Ayur-Ai)**: identifies Ayurvedic leaves from a photo and looks up their uses. Fully offline, no LLM. 98.6% cross-validated accuracy.
- **[onepass-zsc](https://github.com/Jitheswar/TEAM8-onepass-zsc)**: zero-shot text classification in one forward pass for any number of labels, with calibrated probabilities. Team project.

- **[AIDevOps](https://github.com/Jitheswar/KLH-CSE-2026-27-2420030078-AIDevOps)**: ranks vulnerabilities in a live Kubernetes cluster by how exposed each workload really is. Team project.
